# An update of a generic project installs the Java rules

## Symptom

After `update-ai-framework` on a project whose project.json lists the generic stack, `rules/java-enterprise.md` and `sonarqube.md` appear and load on every message.

## Root cause

The read of project.json in install.sh matched only java|drupal|react-ts; with nothing recorded the default `java` was used.

## Fix / solution

Include `generic` in the regex (both places). Covered by the second test of `tests/claude.test.mts` (an update keeps stacks `generic`).
