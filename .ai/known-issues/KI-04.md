# install.ps1 cannot be loaded from \\wsl.localhost

## Symptom

`File … is not digitally signed. You cannot run this script on the current system.`

## Root cause

The default policy refuses scripts from a UNC path, and `-ExecutionPolicy Bypass` on the command line does not apply to the copy loaded from the network share in every policy scope.

## Fix / solution

Run `install.ps1` from a copy of ai-core on a local disk (C:). selftest copies it to %TEMP% first. Check syntax with the PowerShell parser after edits.
