# install.sh stops silently at the code checks step

## Symptom

The installer ends after printing the code checks heading, exit code 1, no message. Seen on a project with no code check to report (generic stack).

## Root cause

`printf … | grep -E '^(OK|OFF|MISS) +[a-z]' | paint` returns 1 when no line matches; with `pipefail` the whole script exits.

## Fix / solution

Wrap every grep whose emptiness is normal: `{ grep … || true; }`. Fixed for the qa lines and the recorded-stack read. Test new greps on a project where they match nothing.
