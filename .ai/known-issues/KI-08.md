# references reports every ticket as an error: key 'None' != file name

## Symptom

`node .ai/scripts/ai.mjs references` prints `ERROR [ticket] … key 'None' != file name` for every ticket created from the framework's template.

## Root cause

The ticket template names the key `jira_key`; `references.ts` and `impact.ts` read `key`.

## Fix / solution

Both read `key ?? jira_key`.

## Pattern to watch

Any tool that reads a front matter field must accept the name the shipped template uses. Check the template before reading a field.

- `framework/scripts/lib/references.ts`
