# Tools tell the user to run scripts that do not exist

## Symptom

doctor / references / codeindex print `run: bash .ai/scripts/knowledge/scan-index.sh --update`; the file is not there.

## Root cause

The framework no longer ships the `scan-*.sh` wrappers; the messages and the generated `call-path:begin` markers still named them.

## Fix / solution

Messages now name `node .ai/scripts/ai.mjs <tool>`; the call-path marker is matched by `CP_RE`/`RS_RE` for any wording, so skills generated with the old marker are rewritten, not duplicated.

- `framework/scripts/lib/callpaths.ts`
- `framework/scripts/lib/callpaths-drupal.ts`
- `framework/scripts/lib/references.ts`
