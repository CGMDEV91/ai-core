# A project installed from the old guidelines repository cannot switch to ai-core

## Symptom

`update-ai-framework` says `No AI framework update` and keeps pointing at the old repository.

## Root cause

The record `guidelines.local.json` names the old source; the project's copy of `update.ts` knows nothing of `--source`.

## Fix / solution

`bin/update-ai-framework.sh` compares the recorded source with its own ai-core and, when different, runs this ai-core's `install.sh --update-methodology --yes`, which writes `framework.local.json` and removes the old record.

- `bin/update-ai-framework.sh`
- `framework/scripts/lib/update.ts`
