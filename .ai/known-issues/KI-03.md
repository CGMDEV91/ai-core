# opencode fails to reload its config (no models) after a plugin update

## Symptom

opencode shows `Failed to reload` and no models after installing the ticket plugin.

## Root cause

opencode calls every exported function of a plugin file as a plugin; a helper exported next to the plugin was called with the wrong arguments.

## Fix / solution

Each plugin file exports exactly one function; the logic lives in `lib/*.ts`. `opencode.test.mts` asserts it and loads the stub the way opencode does.

- `framework/scripts/opencode/plugin/ticket-context.ts`
