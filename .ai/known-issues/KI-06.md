# A command is refused by the gateway: prompt injection attempt detected

## Symptom

`Request blocked: prompt injection attempt detected` when a command runs, only in some projects.

## Root cause

Lines such as `you are in the workspace folder` (and project names starting with `act`) trigger the detector; it is fuzzy.

## Fix / solution

Reword as a fact about the place (`the working directory is the workspace folder`); find the line with `promptcheck`.

- `framework/commands/start.md`
